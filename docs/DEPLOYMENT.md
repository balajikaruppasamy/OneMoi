### Free-plan limits to know
* The **API sleeps after 15 minutes without visitors**. The next request wakes it in about 30–60 s, so the first page load is slow. This is fine for testing; a paid plan ($7/month) removes it.
* 750 free instance hours per month: enough for one always-on service.
* Supabase free projects **pause after 7 days without activity**. Open the Supabase dashboard and click *Restore* if that happens.

## Step 1 — Supabase: connection string + storage bucket

1. Supabase dashboard → your project → **Connect** (top bar) → **Session pooler**.
   (Do *not* use "Direct connection": it is IPv6-only and Render cannot reach it.)
2. Copy the values and build this **.NET connection string** (put your real values in the `<…>` parts):
   ```
   Host=aws-0-<region>.pooler.supabase.com;Port=5432;Database=onemoi;Username=postgres.<project-ref>;Password=<your-db-password>;SSL Mode=Require;Trust Server Certificate=true;Maximum Pool Size=10;Timeout=30
   ```
   * `Database=onemoi` is the database you restored your backup into (use `postgres` if you restored into the default one).
   * `Username` is `postgres.` followed by your project ref, exactly as shown on the Session pooler screen.
3. **Storage** → *New bucket* → name `onemoi` → turn **Public bucket ON** → Create.
4. **Project Settings → API**: copy the **Project URL** (`https://<project-ref>.supabase.co`) and the **service_role** key (secret, never share it).

## Step 2 — Render: create both services from GitHub

1. Go to https://render.com → **Sign up with GitHub** (free, no card).
2. **New → Blueprint** → *Connect* your GitHub account and allow access to **balajikaruppasamy/OneMoi**.
3. Render reads `render.yaml` and shows **onemoi-api** and **onemoi-web**. It asks for the secret values:

   | Variable | Value |
   |---|---|
   | `ConnectionStrings__OneMoi` | the connection string from Step 1.2 |
   | `Supabase__Url` | `https://<project-ref>.supabase.co` |
   | `Supabase__ServiceKey` | the service_role key |

   `Jwt__Key` and `App__OtpSecret` are generated by Render automatically.
4. Click **Apply**. The first build takes about 5–10 minutes (Docker build of .NET 10).
5. Check the API: open `https://onemoi-api.onrender.com/health`. You should see `{"status":"ok","database":"ok"}`.
   Then `https://onemoi-api.onrender.com/swagger`.
6. Open the app: **https://onemoi-web.onrender.com**

> If Render shows different names (e.g. `onemoi-api-abcd.onrender.com`) because the name was taken:
> * edit `src/frontend/onemoi-web/src/environments/environment.prod.ts` → `apiUrl`, and push;
> * in Render → onemoi-api → Environment → set `Cors__Origins__0` to the real web URL.

## Step 3 — Right after the first deployment (important)

The database came from your local backup, so it contains the **demo accounts with known passwords**.
1. Log in at https://onemoi-web.onrender.com as `admin@onemoi.in` / `Admin@123` → **Account & security → Change password**.
2. Do the same for the vendor owners you will keep (or disable the demo users under *Users*).
3. `App__ExposeOtpInResponse = true` shows the OTP on screen, because real SMS is not connected yet. **Anyone can log in as any mobile number while this is on.** Use it only while testing, then set it to `false` in Render → onemoi-api → Environment.

## Day-to-day

| You do | What happens |
|---|---|
| Commit + **Push** in Visual Studio | GitHub Actions builds both apps (✔ / ✖ on GitHub); Render redeploys API and web automatically |
| Add a database migration and push | the API applies it to Supabase on start-up (`Database:AutoMigrate`) |
| Something broken on Render | Render → service → **Logs** |

## Local development keeps working
`OneMoi.Api/appsettings.Development.json` (on your PC only, ignored by Git) holds the local PostgreSQL password and dev keys.
A new developer copies `appsettings.Development.example.json` to `appsettings.Development.json` and fills in their own values.

## Visual Studio 2026 + GitHub
* **Sign in:** File → Account Settings → *Add an account* → **GitHub** → sign in in the browser. Visual Studio stores the token, so pushes need no password.
* **Open the code:** File → Open → Folder → `D:\OneMoi` (or open `src\backend\OneMoi.sln`). The Git menu now shows branch *main* and remote *origin*.
* **Daily work:** **View → Git Changes** (Ctrl+0, Ctrl+G) → write a message → **Commit All** → **Push** (↑).
* **Get changes from GitHub:** Git Changes → **Pull** (↓).
* **See history:** Git → View Branch History.
